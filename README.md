# 🤖 Diva – Your AI Virtual Assistant

[![Live Site](https://img.shields.io/badge/Live-Diva-blueviolet?style=for-the-badge&logo=vercel)](https://diva-iota.vercel.app/)

Diva is your friendly AI virtual assistant built with **Vite + React**.  
She’s not just another chatbot — she can **listen**, **speak**, **respond intelligently**, **search the web**, and **open websites** – all through your voice.  
In simple words, **Diva is the AI who can talk with you**.

---

## 🌐 Live Demo

👉 [Click here to try Diva](https://diva-iota.vercel.app/)

---

## 🛠️ Tech Stack

- ⚡ **Vite** – Lightning-fast frontend tooling
- ⚛️ **React** – UI framework
- 🧠 **Gemini API** – AI response engine
- 🌐 **Web APIs**:
  - `SpeechRecognition` – For voice input
  - `SpeechSynthesis` – For voice output
- 🎨 **Custom CSS** – UI Styling

---

## 🚀 Features

- 🎤 **Voice-activated AI assistant**
- 🗣️ **Text-to-speech** – Diva talks back!
- 🔍 **Google Search** via voice
- 🌐 **Opens websites** with a single command
- 🧠 **AI-generated answers** using Gemini
- 🕒 Tells you the **time** and **date**
- 🧍‍♀️ Responds to phrases like:
  - “What’s your name?”
  - “Who created you?”
  - “Hello Diva” *(auto-activates the mic)*

---

## 🧠 How It Works

1. Say **"Hello Diva"** or click the mic button to activate listening.
2. Diva listens to your command using the Web Speech API.
3. Based on what you say, she can:
   - Generate a smart reply using AI
   - Speak back using `SpeechSynthesis`
   - Open websites
   - Search Google
4. She responds in real-time and continues the conversation like a pro.
